# Memory archive

Entries pruned from `project.md`, `conventions.md`, or `lessons.md` land here when those
files exceed their caps — moved, never deleted, so history is never lost.

Archived entries are **never auto-loaded**. Search here only when investigating something
old (a resurfaced bug, a revived module). Keep the original IDs (C-NNN, L-NNN) so
references in old work items still resolve.
