# Skills hors mission (`teach`, `wizard`, écriture)

Operator ne reprend pas les skills de Matt sans rapport avec le développement gaté : `teach`,
`wizard`, et les skills d'écriture (`writing-beats`, etc.).

## Pourquoi c'est hors périmètre

La mission d'Operator est le développement assisté par IA avec méthode vérifiée — pas la
pédagogie ni la rédaction. Chaque skill distribué a un coût permanent (routage, contexte,
maintenance, audit) ; en ajouter hors mission dilue le routeur et le contrat `op-*`/`operator-*`
(ADR-0005).

## Échappatoires

Aucune nécessaire : ces besoins ne relèvent pas du toolkit. Un utilisateur peut installer les
skills de Matt à côté d'Operator s'il les veut.
