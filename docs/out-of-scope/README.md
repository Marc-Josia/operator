# Refus actés — mémoire des out-of-scope

Un fichier par **concept délibérément écarté** du toolkit Operator, avec le motif et les
échappatoires existantes. Même mécanisme que ce que le toolkit installe chez l'utilisateur
(`.operator/memory/out-of-scope/`, ADR-0017), appliqué à nous-mêmes — dogfooding.

Règles : correspondance par similarité de concept, pas par mot-clé ; avant de proposer ou
d'accepter une évolution, vérifier ici — si le concept recoupe un refus, le signaler avec le
motif ; c'est l'operateur (Marc) qui tranche, jamais un veto automatique. Ne **jamais** consigner
ici un « déjà implémenté » ni un simple report (« pas maintenant ») — uniquement les refus
délibérés. Rouvrir un concept = supprimer ou réécrire son fichier.

Dossier d'environnement de dev, en français, hors distribution (frontière `/src`).
